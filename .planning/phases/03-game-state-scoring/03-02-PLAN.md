    **Step 1: Create useScoreControls hook**

    Create `src/hooks/useScoreControls.ts` using `react-hotkeys-hook`:

    Import `useHotkeys` from `'react-hotkeys-hook'`.
    Read store actions via individual selectors: `addRightScore`, `addLeftScore`, `toggleTurn`, `swapSides`, `rightsTurn`.

    **Keyboard shortcut layout (Claude's discretion — right hand for right team, left hand for left team):**

    Section-aware scoring presets for the ACTIVE team:
    - `1` key: +1 point (speed question, general)
    - `2` key: +2 points (windows of knowledge)
    - `5` key: +5 points (puzzle second solver, debate judge)
    - `8` key: +8 points (windows of knowledge max, minefield wrong penalty as negative)
    - `0` key: +10 points (puzzle first solver)
    - `shift+5` key: +15 points (puzzle/debate max)
    - `shift+6` key: +16 points (minefield correct)
    - `minus` or `-` key: -8 points (minefield wrong — most common negative)

    All presets apply to the ACTIVE team (determined by `rightsTurn`):
    ```typescript
    const addActiveScore = (points: number) => {
      const { rightsTurn, addRightScore, addLeftScore } = useShowStore.getState()
      if (rightsTurn) addRightScore(points)
      else addLeftScore(points)
    }
    ```

    All scoring hotkeys use `{ enableOnFormTags: false }` to prevent firing when typing in CustomScoreInput.

    **Turn and team controls:**
    - `Space`: Toggle turn (`toggleTurn()`) — `{ enableOnFormTags: false, preventDefault: true }`
    - `cmd+shift+s, ctrl+shift+s`: Swap sides (`swapSides()`) — `{ enableOnFormTags: false, preventDefault: true }`

    **Undo/redo:**
    - `cmd+z, ctrl+z`: Undo last scoring action — `{ enableOnFormTags: false, preventDefault: true }`
    - `cmd+shift+z, ctrl+shift+z`: Redo — `{ enableOnFormTags: false, preventDefault: true }`

    The hook returns nothing (void) — it just registers global keyboard listeners. It should be called once in the OperatorControls component.

    **Step 2: Create CustomScoreInput component**

    Create `src/components/operator/CustomScoreInput.tsx`:
    - A compact inline input for entering arbitrary score values
    - Contains: a number input field, +/- toggle, and "Apply" action
    - State: `value: string` (empty by default), `isNegative: boolean` (false by default)
    - The input field uses `type="number"` with `inputMode="numeric"`
    - Press `Enter` to apply the score to the active team:
      ```typescript
      const applyScore = () => {
        const num = parseInt(value)
        if (isNaN(num) || num === 0) return
        const points = isNegative ? -Math.abs(num) : Math.abs(num)
        const { rightsTurn, addRightScore, addLeftScore } = useShowStore.getState()
        if (rightsTurn) addRightScore(points)
        else addLeftScore(points)
        setValue('')  // Clear after apply
      }
      ```
    - Press `Escape` to clear the input and blur it (return focus to global shortcuts)
    - Shows which team will receive the score: display active team name next to input
    - Use shadcn/ui `Input` component and `Button` component for consistent styling
    - The input has a label like "نقاط مخصصة" (Custom Points)
    - Toggle between +/- with a small button next to the input

    **CRITICAL:** `enableOnFormTags: false` in useScoreControls ensures keyboard shortcuts don't fire while the operator is typing a custom score value. When the operator focuses the input, only Enter and Escape are handled (via onKeyDown on the input element itself).
