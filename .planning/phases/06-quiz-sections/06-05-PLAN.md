**AskIntelligentlyPanel.tsx — Operator adaptive zone for ask-intelligently section:**

The section workflow:
1. **Pre-start**: Operator sees the composite animal grid image (thumbnail in the panel) and a "Start" button
2. **Active phase**: After clicking Start: +20 points awarded to active team (the asking team — determined by `rightsTurn`), 120s countdown begins. Operator can deduct 1 point per yes/no question asked. Panel shows remaining points (20 minus askedQuestions) and a "سؤال (Q)" deduction button.
3. **End**: Section ends when timer hits 0, or operator presses E to end early

**Data situation:**
There is NO dedicated data key in `parts` for ask-intelligently. The legacy code hardcodes `{text: "اسأل بذكاء", duration: 120, file: "animals.png", isImage: true}`. This plan follows the same approach — hardcode the 120s duration and reference the composite image.

**Image handling:**
Only a single composite `animals.png` exists in `src/assets/`. This plan displays it as a single image in both the operator panel (small thumbnail) and audience display (full screen). When individual animal images are eventually collected, the grid can be refactored — but for now, the composite image serves as the visual reference.

**Start button handler:**
```typescript
const handleStart = () => {
  // Award 20 points to the asking team (the non-picking team, which is the active team)
  const rightsTurn = useShowStore.getState().rightsTurn
  if (rightsTurn) {
    useShowStore.getState().addRightScore(20)
  } else {
    useShowStore.getState().addLeftScore(20)
  }
  // Start 2-minute countdown
  useTimerStore.getState().setCountdown(120)
  useTimerStore.getState().setCountdownRunning(true)
  // Mark section as started (use askedQuestions = 0 to indicate started vs -1 for not started)
  // Actually, askedQuestions starts at 0 in initialState already, so use a local flag
  setStarted(true)
}
```

Use local `started` state to track whether the section has begun (this is operator-only UI state — the audience display doesn't need to know if we've started, it just shows the grid image always).

**Deduction handler (Q key + click):**
```typescript
useHotkeys('q', () => {
  const state = useShowStore.getState().sectionState
  const remaining = 20 - state.askedQuestions
  if (remaining > 0) {
    const rightsTurn = useShowStore.getState().rightsTurn
    if (rightsTurn) {
      useShowStore.getState().addRightScore(-1)
    } else {
      useShowStore.getState().addLeftScore(-1)
    }
    useShowStore.getState().setSectionState({ askedQuestions: state.askedQuestions + 1 })
  }
}, { enabled: isActive && started, enableOnFormTags: false }, [isActive, started])
```

**End handler (E key):**
```typescript
useHotkeys('e', () => {
  useTimerStore.getState().setCountdownRunning(false)
  setStarted(false)
}, { enabled: isActive && started, enableOnFormTags: false }, [isActive, started])
```

**AskIntelligentlyDisplay.tsx — Audience view for ask-intelligently section:**

The audience display shows the composite `animals.png` image filling the content area. This is a simple display — the audience sees the grid of 72 animals to follow along as the teams play.

**Image approach:**
Since only the composite `animals.png` exists (a single large image containing all 72 animal photos arranged in a grid), display it as a full-width image within the safe area. Use `object-contain` to ensure it fits without cropping on any aspect ratio.

The section title "اسأل بذكاء" is shown above the image. The existing TimerDisplay component shows the countdown timer below.

```typescript
import { useShowStore } from '@/state'
import { useOperatorStore } from '@/state'
import { getContentStyle } from '@/lib/safeArea'
import { TimerDisplay } from '@/components/audience/TimerDisplay'
import { motion } from 'motion/react'
import animalsImage from '@/assets/animals.png'

export function AskIntelligentlyDisplay() {
  const safeArea = useOperatorStore((s) => s.safeArea)
  const contentStyle = getContentStyle(safeArea)

  return (
    <div style={contentStyle} className="flex flex-col items-center justify-center h-full gap-4">
      {/* Section title */}
      <motion.p
        initial={{ opacity: 0, y: -20 }}
        animate={{ opacity: 1, y: 0 }}
        transition={{ duration: 0.4 }}
        className="text-white/70 font-bold text-center"
        style={{ fontSize: 'clamp(1rem, 2vw, 2rem)' }}
      >
        اسأل بذكاء
      </motion.p>

      {/* Animal grid image */}
      <motion.div
        initial={{ opacity: 0, scale: 0.95 }}
        animate={{ opacity: 1, scale: 1 }}
        transition={{ duration: 0.5, ease: [0.4, 0, 0.2, 1] }}
        className="flex-1 w-full max-w-5xl flex items-center justify-center px-4"
      >
        <img
          src={animalsImage}
          alt="72 حيواناً - اسأل بذكاء"
          className="max-w-full max-h-full object-contain rounded-lg"
          loading="eager"
        />
      </motion.div>

      {/* Timer display */}
      <TimerDisplay />
    </div>
  )
}
```

**Key design choices:**
- `loading="eager"` because the image is large (~12MB) and should preload when the section is entered, not lazy-load
- `object-contain` ensures the full grid is visible regardless of audience display aspect ratio
- `max-w-5xl` constrains width on very wide screens to keep the grid readable
- `flex-1` allows the image area to grow and fill available vertical space between title and timer
- `rounded-lg` adds subtle rounding to the image edges

**Future upgrade path:** When individual animal images are collected, this component can be refactored to use a CSS grid of 72 `<img>` tags with click-to-highlight interaction. The sectionState could track a `revealedAnimals: boolean[]` array. For now, the composite image is the functional solution.
