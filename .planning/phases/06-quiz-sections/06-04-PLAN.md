**DebatePanel.tsx — Operator adaptive zone for debate section:**

The debate panel has two phases:
1. **Vote entry phase**: 6 numeric inputs (3 groups × 2 teams) for judge votes. Each group scores 0-3 per team. Max per team: judges (0-9, sum of 3 judges), audience (0-3), guest (0-3). Total max = 15 per team.
2. **Reveal phase**: After operator clicks "Confirm" button, Enter key triggers sequential reveal (debateRevealedCount 0→1→2→3→4).

CRITICAL — Enter key conflict resolution (Research Pitfall 2):
- During vote entry phase (debateVotes === null in store), Enter does NOT trigger reveal. The `useHotkeys('enter', ...)` is gated with `enabled: isActive && debateVotes !== null`.
- Operator fills all 6 inputs, then clicks "تأكيد" (Confirm) button. The button handler writes `debateVotes` to sectionState via `setSectionState({ debateVotes: { right: {...}, left: {...} } })`.
- Once debateVotes is set in the store, Enter hotkey becomes active for the reveal sequence.
- Use `enableOnFormTags: false` on the Enter hotkey so it ONLY fires when no input is focused. This prevents accidental reveal while typing in inputs — operator must Tab out of inputs or click Confirm first.

**Component structure:**

```typescript
import { useState, useRef } from 'react'
import { useShowStore, useTimerStore } from '@/state'
import { useHotkeys } from 'react-hotkeys-hook'
```

Local state for the form inputs (before confirmation):
- `judgesRight`, `judgesLeft`: number (combined score of 3 judges, 0-9)
- `audienceRight`, `audienceLeft`: number (0-3)
- `guestRight`, `guestLeft`: number (0-3)

These are local `useState` values used only during the entry phase. Once confirmed, they're written to the store's `debateVotes` and the form inputs become read-only.

**Data access:**
```typescript
const debateTopic = data?.parts.debate?.text ?? 'النقاش'
const debateDuration = data?.parts.debate?.duration ?? 60
```
Note: `parts.debate` is a single `QuestionItem`, not an array. There's one debate topic per episode.

**Timer integration:**
The operator can use T to start/stop the debate timer (first round 60s, second round 40s). Add T hotkey using the same pattern as PuzzlePanel. The operator manually sets the timer duration for each round.

- T: start/stop countdown timer (uses `debateDuration` from data for first round)
- Shift+T: reset timer and set to 40 (second round duration)

**Confirm handler:**
```typescript
const handleConfirm = () => {
  // Validate totals: each group 0-3, judges combined 0-9
  const votes = {
    right: { judges: judgesRight, audience: audienceRight, guest: guestRight },
    left: { judges: judgesLeft, audience: audienceLeft, guest: guestLeft },
  }
  useShowStore.getState().setSectionState({ debateVotes: votes })
}
```

**Reveal hotkey (Enter — only active after confirm):**
```typescript
const debateVotes = useShowStore((s) => s.sectionState.debateVotes)
const debateRevealedCount = useShowStore((s) => s.sectionState.debateRevealedCount)

useHotkeys('enter', () => {
  const state = useShowStore.getState().sectionState
  if (state.debateRevealedCount < 3) {
    // Reveal next slot
    useShowStore.getState().setSectionState({
      debateRevealedCount: state.debateRevealedCount + 1
    })
  } else if (state.debateRevealedCount === 3) {
    // All revealed — apply total scores to both teams
    const votes = state.debateVotes!
    const rightTotal = votes.right.judges + votes.right.audience + votes.right.guest
    const leftTotal = votes.left.judges + votes.left.audience + votes.left.guest
    useShowStore.getState().addRightScore(rightTotal)
    useShowStore.getState().addLeftScore(leftTotal)
    // Mark as fully applied (count = 4 means "scores applied")
    useShowStore.getState().setSectionState({ debateRevealedCount: 4 })
  }
}, {
  enabled: isActive && debateVotes !== null && (debateRevealedCount ?? 0) < 4,
  enableOnFormTags: false
}, [isActive, debateVotes, debateRevealedCount])
```

**DebateDisplay.tsx — Audience view for debate section:**

The audience display for the debate section has two states:
1. **Before votes confirmed**: Shows the debate topic text prominently (similar to other section displays)
2. **During/after reveal**: Shows 3 vote slots that animate in one at a time as `debateRevealedCount` increases

**Debate topic display:**
When `debateVotes === null` (no votes confirmed yet), show the debate topic text centered on screen. This is visible during the debate itself (teams arguing). Use the same text styling pattern as other section displays (clamp font sizing, white, drop-shadow).

**Vote reveal slots:**
When `debateVotes !== null`, transition to the vote reveal view. Each slot is a card showing:
- Group label (الحكام / الجمهور / الضيف)
- Right team score : Left team score

Use team names from `data.rightTeamName` / `data.leftTeamName` in the header.

**Animation per slot (per Research Pattern 5):**
Each slot animates in with a dramatic entrance when `debateRevealedCount` reaches its threshold:
- Slot 1 (Judges): visible when `debateRevealedCount >= 1`
- Slot 2 (Audience): visible when `debateRevealedCount >= 2`
- Slot 3 (Guest): visible when `debateRevealedCount >= 3`

Use `AnimatePresence` with staggered `motion.div` elements:
```typescript
initial={{ scale: 0.3, opacity: 0, y: 60 }}
animate={{ scale: 1, opacity: 1, y: 0 }}
transition={{ duration: 0.6, ease: [0.4, 0, 0.2, 1] }}
```

This creates a "card flip" feel — each slot scales up from small + faded as it reveals.

**Total scores display:**
When `debateRevealedCount >= 3` (all revealed), show a total row below the 3 slots with the combined score for each team, using larger text and a dividing line above.

When `debateRevealedCount === 4` (scores applied), add a subtle "✓" checkmark or green glow to indicate finality.

**Layout:**
```
┌──────────────────────────────────────────────┐
│            النقاش: [topic text]               │  ← shown before votes
│                                              │
│   ┌──────────┐  ┌──────────┐  ┌──────────┐  │  ← slots appear L→R
│   │  الحكام   │  │  الجمهور  │  │  الضيف   │  │
│   │   7 : 5   │  │   3 : 2   │  │   2 : 3   │  │
│   └──────────┘  └──────────┘  └──────────┘  │
│                                              │
│              المجموع: 12 : 10                 │  ← after all 3 revealed
└──────────────────────────────────────────────┘
```

The slots are arranged horizontally (`flex gap-8 justify-center`). Each slot card uses `rounded-2xl border-2 border-white/30 bg-white/10 backdrop-blur-sm p-6`. Score numbers use `western-numerals text-amber-300 font-bold` at a large size (clamp 3rem-6rem). The ":" separator uses `text-white/40`.

**Implementation:**

```typescript
import { useShowStore } from '@/state'
import { useOperatorStore } from '@/state'
import { getContentStyle } from '@/lib/safeArea'
import { motion, AnimatePresence } from 'motion/react'

const DEBATE_SLOTS = [
  { key: 'judges', label: 'الحكام', threshold: 1 },
  { key: 'audience', label: 'الجمهور', threshold: 2 },
  { key: 'guest', label: 'الضيف', threshold: 3 },
] as const

export function DebateDisplay() {
  const data = useShowStore((s) => s.data)
  const sectionState = useShowStore((s) => s.sectionState)
  const safeArea = useOperatorStore((s) => s.safeArea)
  const contentStyle = getContentStyle(safeArea)

  const debateTopic = data?.parts.debate?.text ?? 'النقاش'
  const debateVotes = sectionState.debateVotes
  const revealedCount = sectionState.debateRevealedCount

  // Pre-reveal: show topic
  if (!debateVotes) {
    return (
      <div style={contentStyle} className="flex flex-col items-center justify-center h-full">
        <motion.p
          initial={{ opacity: 0, y: 30 }}
          animate={{ opacity: 1, y: 0 }}
          transition={{ duration: 0.5 }}
          className="text-white font-bold text-center drop-shadow-lg px-8 whitespace-pre-line"
          style={{ fontSize: 'clamp(2rem, 4vw, 5rem)' }}
        >
          {debateTopic}
        </motion.p>
      </div>
    )
  }

  // Reveal phase
  const rightTeamName = data?.rightTeamName ?? 'الأيمن'
  const leftTeamName = data?.leftTeamName ?? 'الأيسر'
  const rightTotal = debateVotes.right.judges + debateVotes.right.audience + debateVotes.right.guest
  const leftTotal = debateVotes.left.judges + debateVotes.left.audience + debateVotes.left.guest

  return (
    <div style={contentStyle} className="flex flex-col items-center justify-center h-full gap-8">
      {/* Team name headers */}
      <div className="flex justify-center gap-24 w-full max-w-4xl">
        <span className="text-white font-bold" style={{ fontSize: 'clamp(1.2rem, 2vw, 2.5rem)' }}>
          {rightTeamName}
        </span>
        <span className="text-white/40 font-bold" style={{ fontSize: 'clamp(1.2rem, 2vw, 2.5rem)' }}>
          VS
        </span>
        <span className="text-white font-bold" style={{ fontSize: 'clamp(1.2rem, 2vw, 2.5rem)' }}>
          {leftTeamName}
        </span>
      </div>

      {/* Vote reveal slots */}
      <div className="flex gap-8 justify-center items-end">
        <AnimatePresence>
          {DEBATE_SLOTS.map((slot) =>
            revealedCount >= slot.threshold ? (
              <motion.div
                key={slot.key}
                initial={{ scale: 0.3, opacity: 0, y: 60 }}
                animate={{ scale: 1, opacity: 1, y: 0 }}
                transition={{ duration: 0.6, ease: [0.4, 0, 0.2, 1], delay: 0.1 }}
                className="flex flex-col items-center rounded-2xl border-2 border-white/30 bg-white/10 backdrop-blur-sm px-8 py-6"
              >
                <span className="text-white/70 font-medium mb-3" style={{ fontSize: 'clamp(0.9rem, 1.5vw, 1.5rem)' }}>
                  {slot.label}
                </span>
                <div className="flex items-center gap-3">
                  <span className="western-numerals text-amber-300 font-bold" style={{ fontSize: 'clamp(2.5rem, 5vw, 5rem)' }}>
                    {debateVotes.right[slot.key]}
                  </span>
                  <span className="text-white/40 font-bold" style={{ fontSize: 'clamp(2rem, 4vw, 4rem)' }}>
                    :
                  </span>
                  <span className="western-numerals text-amber-300 font-bold" style={{ fontSize: 'clamp(2.5rem, 5vw, 5rem)' }}>
                    {debateVotes.left[slot.key]}
                  </span>
                </div>
              </motion.div>
            ) : null
          )}
        </AnimatePresence>
      </div>

      {/* Total row — visible after all 3 slots revealed */}
      <AnimatePresence>
        {revealedCount >= 3 && (
          <motion.div
            key="totals"
            initial={{ opacity: 0, y: 20 }}
            animate={{ opacity: 1, y: 0 }}
            transition={{ duration: 0.5, delay: 0.3 }}
            className="flex items-center gap-4 mt-4"
          >
            <span className="text-white/60 font-medium" style={{ fontSize: 'clamp(1rem, 1.5vw, 1.8rem)' }}>
              المجموع
            </span>
            <span className="western-numerals text-white font-bold" style={{ fontSize: 'clamp(2rem, 4vw, 4rem)' }}>
              {rightTotal}
            </span>
            <span className="text-white/40 font-bold" style={{ fontSize: 'clamp(1.5rem, 3vw, 3rem)' }}>
              :
            </span>
            <span className="western-numerals text-white font-bold" style={{ fontSize: 'clamp(2rem, 4vw, 4rem)' }}>
              {leftTotal}
            </span>
            {revealedCount === 4 && (
              <motion.span
                initial={{ scale: 0 }}
                animate={{ scale: 1 }}
                transition={{ type: 'spring', stiffness: 300, damping: 20 }}
                className="text-green-400 text-2xl"
              >
                ✓
              </motion.span>
            )}
          </motion.div>
        )}
      </AnimatePresence>
    </div>
  )
}
```
