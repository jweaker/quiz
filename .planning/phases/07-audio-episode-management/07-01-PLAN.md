<task type="auto">
  <name>Task 1: AudioManager singleton with GainNode routing and useAudio hook</name>
  <files>src/lib/audioManager.ts, src/hooks/useAudio.ts, src/state/operatorStore.ts, src/lib/shortcutRegistry.ts</files>
  <action>
1. Create `src/lib/audioManager.ts` — class-based AudioManager singleton:
   - Single `AudioContext` created lazily on first play/preload call
   - GainNode routing chain: 4 category GainNodes (timer, feedback, transition, section) → masterGain → ctx.destination
   - `AudioCategory` type: `'timer' | 'feedback' | 'transition' | 'section'`
   - Sound ID to category mapping: a `SOUND_CATEGORIES` record mapping each sound ID string to its AudioCategory. Timer category: tick, timer-warning, timer-urgent, timer-expire. Feedback: correct, wrong, score-milestone. Transition: section-enter, section-exit, show-intro, show-outro. Section: minefield-danger, minefield-correct, minefield-wrong, debate-reveal, puzzle-solve, thinking-loop, pass-verse.
   - `buffers: Map<string, AudioBuffer>` for preloaded audio
   - `preloadAll()`: Fetches all sound files from `/sounds/{id}.mp3` (or .wav for tick), decodes to AudioBuffer, stores in map. Use Promise.allSettled so one missing file doesn't break all audio. Log warnings for failures.
   - `play(soundId: string, options?: { gain?: number })`: Gets buffer from map, creates BufferSourceNode, routes through the correct category GainNode based on SOUND_CATEGORIES mapping, starts playback. Handle AudioContext suspension (resume if suspended). Fire-and-forget pattern.
   - `setMasterVolume(value: number)`: Sets masterGain.gain.value (0-1)
   - `setCategoryVolume(category: AudioCategory, value: number)`: Sets category GainNode gain (0-1)
   - `toggleMute()`: If not muted, store current masterGain value and set to 0. If muted, restore previous value. Track muted state as boolean.
   - `isMuted`: getter for mute state
   - `dispose()`: Close AudioContext, clear buffers
   - Export singleton instance: `export const audioManager = new AudioManager()`

2. Create `src/hooks/useAudio.ts` — thin React hook wrapping singleton:
   - Imports `audioManager` singleton
   - On mount: call `audioManager.preloadAll()` (idempotent — skip if already loaded)
   - Reads volume/mute state from `useOperatorStore` and syncs to audioManager via useEffect (when masterVolume, timerVolume, feedbackVolume, transitionVolume, sectionVolume change)
   - Returns: `{ play, toggleMute, isMuted }` — delegates to audioManager methods
   - `play` is a stable callback (useCallback wrapping audioManager.play)
   - `isMuted` is reactive — use useState synced from audioManager state

3. Add audio volume state to `src/state/operatorStore.ts`:
   - Add fields: `masterVolume: number` (default 0.8), `timerVolume: number` (default 1), `feedbackVolume: number` (default 1), `transitionVolume: number` (default 0.7), `sectionVolume: number` (default 1), `audioMuted: boolean` (default false)
   - Add setters: `setMasterVolume`, `setTimerVolume`, `setFeedbackVolume`, `setTransitionVolume`, `setSectionVolume`, `setAudioMuted`
   - Add all volume fields to the `partialize` function so they persist in localStorage
   - Keep `audienceWindowConnected` excluded from persistence as before

4. Add mute shortcut to `src/lib/shortcutRegistry.ts`:
   - Add entry: `'audio-mute': { keys: 'm', label: 'كتم الصوت', category: 'general', description: 'كتم/تشغيل الصوت' }`
  </action>

Verify operatorStore has masterVolume, timerVolume, feedbackVolume, transitionVolume, sectionVolume fields. Verify shortcutRegistry has audio-mute entry.
  </verify>
  <done>AudioManager singleton with GainNode routing chain exists. useAudio hook wraps it for React. operatorStore persists volume settings. Mute shortcut registered.</done>
