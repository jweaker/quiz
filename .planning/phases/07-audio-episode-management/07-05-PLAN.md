  <name>Task 1: Paste parser and reusable QuestionListEditor with BulkPasteDialog</name>
  <files>src/lib/pasteParser.ts, src/screens/editor/components/QuestionListEditor.tsx, src/screens/editor/components/BulkPasteDialog.tsx</files>
  <action>
1. **Create `src/lib/pasteParser.ts`** — paste format detection and parsing:
   - `detectPasteFormat(text: string): 'json' | 'tsv' | 'qa-pairs' | 'lines'`
     - If text starts with `{` or `[`: try JSON.parse → 'json'
     - If most lines contain `\t`: 'tsv'
     - If lines match Q/A patterns (Q: / A: or س: / ج: or numbered with indented answers): 'qa-pairs'
     - Fallback: 'lines'
   - `parsePastedQuestions(text: string): Question[]`
     - Detect format, then parse accordingly:
     - JSON: parse, extract if it's an array of objects with text/answer fields
     - TSV: split lines by tab, first column = text, second = answer, third = duration (optional), fourth = marks (optional)
     - QA pairs: match patterns, pair up question + answer lines
     - Lines: each non-empty line becomes a question with empty answer
     - Return Question[] using QuestionSchema defaults for missing fields
   - Handle Arabic question marks `؟` and Arabic-Indic numerals `١٢٣` in detection

2. **Create `src/screens/editor/components/QuestionListEditor.tsx`** — reusable component:
   - Renders a list of Question items with editable fields per row: text (textarea), answer (input), duration (number), marks (number)
   - Add button at bottom to append a new blank question
   - Remove button (X icon) per row to delete a question
   - "لصق مجمّع" (Bulk Paste) button opens BulkPasteDialog
   - Props: `questions: Question[]`, `onChange: (questions: Question[]) => void`, `errors?: Record<string, string[]>`, `showMarks?: boolean` (some sections don't use marks), `showDuration?: boolean`
   - Each field shows inline error if present in errors prop

3. **Create `src/screens/editor/components/BulkPasteDialog.tsx`:**
   - shadcn/ui Dialog component
   - Large textarea for pasting
   - On paste/change: calls `parsePastedQuestions()` and shows preview of parsed result
   - Preview shows: "تم اكتشاف X سؤال" (Detected X questions) + format type + first 3 questions preview
   - "إضافة" (Add) button: appends parsed questions to existing list and closes dialog
   - "استبدال" (Replace) button: replaces all questions with parsed ones
   - "إلغاء" (Cancel) button: closes without action
  </action>
