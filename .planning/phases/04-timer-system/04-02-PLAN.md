  <files>

  <action>
1. Create `src/hooks/useChessClock.ts`:
   ```typescript
   export function useChessClock(options?: { onTimerExpired?: (expiredTeam: 'right' | 'left') => void })
   ```
   - Import `setInterval`, `clearInterval` from 'worker-timers'.
   - Read `activeTimer`, `rightTimeMs`, `leftTimeMs` from useTimerStore.
   - Use a single useEffect watching `activeTimer`:
     - If `activeTimer === null`: no interval, return early.
     - If activeTimer is 'right' or 'left': start worker-timers setInterval at 100ms.
     - On each tick:
       - Use performance.now() to track actual elapsed time since interval started.
       - Compute `newTimeMs = previousTimeMs - actualElapsedSincLastTick`.
       - Track the start time with a ref, compute delta each tick.
       - Update the active team's time: `useTimerStore.getState().setRightTimeMs(newTime)` or `setLeftTimeMs(newTime)`.
       - If newTimeMs <= 0: set to 0, set activeTimer to null, call onTimerExpired(activeTeam).
     - Cleanup: clearInterval (from worker-timers).
   - Expose actions:
     - `startClock(team: 'right' | 'left')`: sets activeTimer to team.
     - `switchClock()`: if activeTimer is 'right', set to 'left', vice versa. If null, do nothing.
     - `pauseClock()`: sets activeTimer to null.
     - `resetClock(durationMs = 100_000)`: calls timerStore.resetChessClock(durationMs).
   - Expose computed values:
     - `rightPoints: Math.floor(rightTimeMs / 5000)` — points preview for right team.
     - `leftPoints: Math.floor(leftTimeMs / 5000)` — points preview for left team.
     - `rightSeconds: Math.ceil(rightTimeMs / 1000)` — display seconds.
     - `leftSeconds: Math.ceil(leftTimeMs / 1000)` — display seconds.
   - Integrate audio cues: use useTimerAudio() inside the hook.
     - Track thresholds (10, 5, 0) with a Set ref, reset when activeTimer changes.
     - When active team's remaining seconds crosses 10, 5, or 0: call playBeep(threshold).
   - CRITICAL: Single `activeTimer` field ensures mutual exclusion — only one team's clock ticks at a time, atomic switching.
  </action>

    - `grep "Math.floor.*5000" src/hooks/useChessClock.ts` shows points conversion
    - `grep "worker-timers" src/hooks/useChessClock.ts` shows correct import
  </verify>
  <done>
    - Chess clock ticks only the active team's timer (mutual exclusion via single activeTimer field)
    - Switching is atomic (one state update toggles activeTimer)
    - Points conversion: Math.floor(remainingMs / 5000) for conservative rounding
    - Audio cues fire at 10s, 5s, 0s thresholds for the active timer
    - Timer expired callback fires when a team hits 0
