   ```typescript
   interface TimerState {
     // General countdown
     countdownRemaining: number      // seconds remaining
     countdownRunning: boolean
     countdownDuration: number       // total duration in seconds

     // Chess clock (Poetic Chase)
     rightTimeMs: number             // right team remaining (ms)
     leftTimeMs: number              // left team remaining (ms)
     activeTimer: 'right' | 'left' | null  // which clock is ticking

     // Poetic Chase
     requiredLetter: string | null   // letter displayed on audience screen
     verseCount: { right: number; left: number }  // verse points per team

     // Actions
     setCountdown: (duration: number) => void
     setCountdownRemaining: (remaining: number) => void
     setCountdownRunning: (running: boolean) => void
     setActiveTimer: (active: 'right' | 'left' | null) => void
     setRightTimeMs: (ms: number) => void
     setLeftTimeMs: (ms: number) => void
     setRequiredLetter: (letter: string | null) => void
     addVerse: (team: 'right' | 'left') => void
     resetChessClock: (durationMs?: number) => void
     resetTimer: () => void
   }
   ```
   - Wrap with `broadcast(persist(creator), 'quiz-timer-state')` — same pattern as showStore but use a DIFFERENT BroadcastChannel name ('quiz-timer-state') and localStorage key ('timer-storage').
   - Do NOT wrap with temporal middleware — undo should NOT rewind the clock (per research recommendation).
   - Default chess clock: 100_000ms (100 seconds) per team.
   - `resetChessClock(durationMs = 100_000)` resets both timers to durationMs and activeTimer to null, verseCount to {right:0, left:0}, requiredLetter to null.
   - `resetTimer()` resets countdown fields to defaults (remaining: 0, running: false, duration: 0).

4. Create `src/hooks/useCountdown.ts` — drift-corrected countdown hook:
   - Import `setInterval` and `clearInterval` from 'worker-timers' (NOT from window).
   - Accept params: `{ onTick?: (remaining: number) => void, onComplete?: () => void, onThreshold?: (seconds: number) => void }`
   - Read countdownRunning, countdownDuration from useTimerStore.
   - When countdownRunning becomes true:
     - Record `startTime = performance.now()`
     - Start worker-timers setInterval at 100ms (sub-second for smoother updates).
     - On each tick: calculate `elapsed = performance.now() - startTime`, `remaining = Math.max(0, Math.ceil((durationMs - elapsed) / 1000))`.
     - Update timerStore.setCountdownRemaining(remaining).
     - Call onTick(remaining) if provided.
     - When remaining crosses 10, 5, or 0 thresholds, call onThreshold(threshold).
     - When remaining hits 0: clearInterval, setCountdownRunning(false), call onComplete().
   - When countdownRunning becomes false (pause): clearInterval.
   - Return cleanup in useEffect: always clearInterval with the worker-timers clearInterval.
   - CRITICAL: Import clearInterval from 'worker-timers', NOT use window.clearInterval.
   - Export named: `export function useCountdown(...)`.
   - Track thresholds already fired with a Set to avoid duplicate calls (reset Set when countdown starts).
  </action>
