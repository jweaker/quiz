1. Create `src/hooks/usePassMechanic.ts`:
   - Implements Poetic Chase pass rules:
     **Pass flow:**
     a. Team A is reciting, can't continue → operator triggers "pass".
     b. Verse goes to Team B → Team B gets +1 point (for receiving the pass).
     c. Clock switches to Team B (Team B's time now running).
     d. If Team B answers correctly with the required letter → +1 additional point AND Team B can return the same letter to Team A.
     e. If Team B uses a new letter (not the required one) → no extra point AND Team B cannot return the passed letter.

   - State tracking needed (local state in the hook, NOT in the store — this is transient pass flow state):
     ```typescript
     const [passActive, setPassActive] = useState(false)
     const [passedToTeam, setPassedToTeam] = useState<'right' | 'left' | null>(null)
     ```

   - Actions:
     - `passVerse()`: Called when active team passes.
       - Determine receiving team (opposite of activeTimer).
       - Award +1 point to receiving team: `addRightScore(1)` or `addLeftScore(1)`.
       - Switch clock to receiving team via useTimerStore.getState().setActiveTimer(receivingTeam).
       - Set passActive = true, passedToTeam = receivingTeam.
     - `correctAnswer()`: Called when current team answers correctly.
       - Add verse count: `useTimerStore.getState().addVerse(activeTeam)`.
       - If passActive AND answering team === passedToTeam: award +1 additional point.
       - Reset passActive.
       - Switch clock back (clock switches on each verse).
     - `wrongAnswer()`: Called when verse is incorrect/time runs out for that verse.
       - Reset passActive.
       - Switch clock.
     - `resetPass()`: Clears pass state.

   - Register keyboard shortcuts (useHotkeys):
     - `'g'` — pass verse (mnemonic: "give")
     - `'v'` — correct verse (mnemonic: "verse")
     - `'x'` — wrong/skip verse
     - All with `enableOnFormTags: false`.

   - Return: `{ passVerse, correctAnswer, wrongAnswer, resetPass, passActive, passedToTeam }`
