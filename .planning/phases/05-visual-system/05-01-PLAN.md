      - `sectionWipe: { duration: 0.4, ease: 'easeInOut' }` (400ms, cinematic wipe)

      - `typewriterStagger: { staggerChildren: 0.03 }` (30ms between letters)

    - `wipeVariants` function accepting direction ('left' | 'right' | 'up' | 'down') returning `enter`, `center`, `exit` keyframes for x/y translation at 100%/-100%
    - `sectionBackgrounds` map: record of section type string keys to CSS gradient strings. Default blue gradient `radial-gradient(circle, rgba(89,133,227,1) 0%, rgba(20,37,74,1) 100%)`, minefield gets dark red/black `radial-gradient(circle, rgba(60,10,10,1) 0%, rgba(15,5,5,1) 100%)`, debate gets warm tone, etc. Export as `getSectionBackground(sectionType: string): string`.

    Create `src/hooks/usePrefersReducedMotion.ts`:
    - SSR-safe default: start with `true` (reduced)
    - useEffect checks `window.matchMedia('(prefers-reduced-motion: no-preference)')`, sets state
    - Listens for preference changes via `addEventListener('change')`
    - Returns boolean `prefersReducedMotion`

    - Wrap the entire app (inside ErrorBoundary, outside BrowserRouter) with `<MotionConfig reducedMotion="user" transition={{ duration: 0.3, ease: 'easeOut' }}>`
    - This auto-disables transform/layout animations when user prefers reduced motion
