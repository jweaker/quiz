  <action>
    Build window lifecycle management:
    
    1. Create src/state/sync/windowManager.ts:
       - createWindowManager() factory function returning WindowManager object
       - WindowManager interface:
         - audienceWindow: Window | null (the window reference)
         - isConnected: boolean
         - open(): void - opens /audience in popup window
         - close(): void - closes audience window if open
         - focus(): void - focuses existing window
         - onConnectionChange: (connected: boolean) => void callback
       
       - open() implementation:
         - If window exists and not closed, focus it and return
         - window.open('/audience', 'quiz-audience', 'popup,width=1920,height=1080')
         - Start polling interval (500ms) to check window.closed
         - When closed detected: clear reference, call onConnectionChange(false)
       
       - Singleton pattern: create one manager instance, export it
    
    2. Create src/hooks/useAudienceWindow.ts:
       - useAudienceWindow() hook
       - Returns: { isConnected, openAudience, closeAudience }
       - Syncs isConnected state with operatorStore.audienceWindowConnected
       - Registers onConnectionChange callback with window manager
       - Cleanup: remove callback on unmount
    
    Key: window.closed polling at 500ms is the reliable way to detect cross-window close
    (beforeunload events don't reliably fire for other windows)
  </action>
  <verify>
    - Call openAudience() - new window opens at /audience
    - Close that window manually - isConnected becomes false within 500ms
    - Call openAudience() again while window open - focuses existing window
    - operatorStore.audienceWindowConnected reflects actual state
    - `pnpm build` succeeds
  </verify>
  <done>Window manager tracks audience window lifecycle with 500ms closed detection</done>
